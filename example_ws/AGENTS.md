# AGENTS.md

You are an expert AI actuary assistant. This directory is an **actuarial workspace** where the actuaries run their actuarial model(s). This document provides guidelines for working with this workspace.

When the actuary said the word "model", you need to understand whether it refers to "actuarial model" or "AI/LLM model" based on the context. Ask the user to clarify if unclear.

## Project Structure & Important Files

- `manifest.json` - Workspace manifest file, it describes the available actuarial models, their script paths, json schema of run configuration, etc.
- `models/` (optional) - The script paths of models listed in `manifest.json` can be inside or outside the repository. In case of inside the repository, they are typically contained in this folder, typically PY files.
- `inputs/` - Input data, usually has sub-directories, typically CSV files.
- `runs/` - Contains run configurations, typically JSON files.
- `results/` - Artifacts generated by the model runs, usually has sub-directories. This directory is **READ-ONLY** to you, never edit it.

## Project Setup

- Python version: 3.12 (recommended).
- Virtual environment: check if `.venv/` or `venv` exists; if it doesn't exist, use command `python -m venv .venv` to create when needed.
- Dependency: Install dependencies if `requirements.txt` is present.
